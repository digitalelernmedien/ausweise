# ausweise

Über diese Schulungs-App
Diese Anwendung dient ausschliesslich Ausbildungszwecken. Sie wurde speziell dafür entwickelt, theoretisches Wissen in die praktische Anwendung zu überführen. Insbesondere soll sie im Szenarientraining und bei Rollenspielen eingesetzt werden.

Funktionen:

Simulation von Datenbankabfragen.
Darstellung von Trefferszenarien (Fahndungen, Einreisesperren, Sachfahndung).
Wichtig: Alle in dieser App angezeigten Daten und Personenprofile sind frei erfunden.
A+W Ausbildung, Digitale Lernmedien, edvausbildung@police.be.ch
